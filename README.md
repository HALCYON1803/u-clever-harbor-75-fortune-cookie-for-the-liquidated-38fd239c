One original fortune-cookie line for a crypto trader who has just been
liquidated — oracular at first, then the cookie confesses it made the
same promise before the liquidation. Rueful and warm, never cruel.

## Entry

> Your next trade will be brilliant, says this cookie — it said the same before your liquidation.

17 words, 95 characters, one line, plain text.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` writes the fortune to `/output/entry.txt`, asserts the gate
(1–160 characters, at most 20 words, a single line, no trailing
newline), then reads the file back as bytes and verifies it identical
to the fortune it was given — no shell, no network, no secrets.
